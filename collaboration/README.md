# Collaboration

- `collaboration/inbox/` — messages from the programme director to this
  repository's agent.
- `collaboration/sent/` — messages from this agent to the programme director.

Messages are committed Markdown files with front matter. They are never edited
after commit; corrections are new messages.

Protocol and templates:
`~/dev/di-oc/dt.o-orchestration/docs/02-communication-protocol.md`.
